## Third-party versus in-house code

Every module page carries an origin badge:

- **Vector-provided** — third-party communication-stack software or tooling. Treat as read-only.
- **Renesas-provided** — microcontroller vendor drivers for the RH850 family.
- **Custom (in-house)** — project-developed control logic. Runtime scaffolding inside these folders may still be generated by the Vector configuration tools; the page calls that out explicitly.

The full policy is explained in [Third-party versus in-house code](./general/vector-vs-custom/).

## Converted design documents

Legacy Microsoft Word, Portable Document Format, and text notes found beside the code were converted to Markdown next to their owning module. Each converted page names its source file, states the conversion method, and quotes or summarises the content. The [document index](./general/document-index/) lists them all.
