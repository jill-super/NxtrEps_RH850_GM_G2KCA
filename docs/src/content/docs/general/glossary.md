### Reading message proxies

A proxy such as `General Motors Message 0x1F1 on High Speed Bus` means the Application Software input or output proxy for that controller-area-network identifier on the high-speed bus. `Chassis Expansion` proxies serve the chassis-expansion bus. `Serial Communication Input Proxy` and `Serial Communication Output Proxy` fan vehicle signals into and out of the steering functions.
